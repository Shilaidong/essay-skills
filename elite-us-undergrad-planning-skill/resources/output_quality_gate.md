# Output Quality Gate

A report is not ready until it passes these checks:

## Content

- [ ] Opening names are evidenced only; no pinyin-guessed Chinese legal name.
- [ ] The first section explains the current file in parent language, not `招生官式诊断`.
- [ ] Each numbered section starts with `> **这一节的结论。**`
- [ ] Current facts are detailed and source-grounded.
- [ ] Missing information is `还需要补充`, not guessed.
- [ ] Three core risks are concrete and actionable.
- [ ] School strategy includes exact programs, not just school names.
- [ ] School list is attributed to 内部数据库 and 学校官网, with no catalog-gap language.
- [ ] Main 3 schools have trigger conditions when requested.
- [ ] SAT/TOEFL/ACT/IELTS plan is consistent with current baseline.
- [ ] Research/project plan includes data, controls/evaluation, outputs, and compliance when relevant.
- [ ] Core activity and competition pathways are truthful and conditional.
- [ ] Every competition/activity pathway states either its advancement/selection mechanism or that there is no formal advancement.
- [ ] Timeline has months and key weeks.

## Style

- [ ] Chinese is parent-facing and professional, not peer-consultant jargon and not a pep talk.
- [ ] No `画像`, `库内`, SQLite, subagent, `小白`, `闭环`, `抓手`, `赛道`.
- [ ] No `v2` / `修改版` in filename or body.
- [ ] Tables are concise and not too wide.
- [ ] No generic “do research / do internship / volunteer more” language without outputs.
- [ ] No overpromising admission odds or advancement results.
- [ ] No unverified claims.

## Artifacts

- [ ] Markdown opens cleanly.
- [ ] Word opens cleanly on cream page `F8F5ED` with dark ink; table headers are dark text on `#E6F5EE`.
- [ ] Word chart is an embedded image/chart.
- [ ] Image paths work in Markdown.
- [ ] File names are the finished names, overwritten in place.
