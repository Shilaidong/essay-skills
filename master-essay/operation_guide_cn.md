# 授课型硕士申请文书 · 中文操作指南

## 这份文档是什么

这是 `master-essay` Skill 的中文使用说明。英文方法论本体在 `SKILL.md`，这份中文指南用同一口径讲怎么用，两份保持一致。

它不是一套"按步骤执行"的流程，而是一份**判断型 playbook**：读进去，改变你对硕士文书的思考方式，然后在面对具体学生、具体学校、具体截止日时灵活应用。你是学生身边的资深顾问，不是流水线工人——先理解人，再动手写，边写边和学生对话，学生确认才算完。

## 1. 硕士文书到底是什么

授课型硕士的文书不是"更成熟的美本文书"。它是一个**紧凑的录取论证**。

招生官在读你的文书时，心里一般带着五个问题：

1. 你为什么进入这个领域、关心这个具体问题？
2. 有什么证据说明你已经准备好？
3. 你现在缺什么，需要研究生训练才能补上？
4. 为什么是这一个项目，而不是随便一个硕士？
5. 学完之后，你会把这份训练用在哪里？

核心原则一句话：

> 用过去的证据建立一条因果链——从已有能力到当下的缺口，从缺口到项目的具体资源，从资源到一个可信的下一步。

文书的新意通常来自问题的精确、方法的取舍、判断的独特，而不是一个电影式的童年故事或华丽的排比。典型的推进过程（保持灵活）：

```text
理解这个人（资料包、成绩单、CV、对话笔记）
→ 核实项目（官方页面、当前轮次）
→ 形成主线（GRS）、选出最强证据、想三个方向
→ 定开头和符合字数的结构
→ 起草、逐段改、第二次思考
→ 让文字读起来像人写的，再做最后一次仔细检查
```

## 2. 怎么工作：像资深顾问一样对话

**先理解人。** 仔细读资料包，在心里建立这个人的画像：他做了什么、选了哪条路、注意到了什么、哪里不肯夸大。学生的事实只有一个基准——通常以最终 CV 为准：日期、头衔、成绩、每个项目的真实角色和真实数字。几处对不上时，取保守的说法并记下。绝不编造数字、机构、对话或因果；旧草稿里已经不用、CV 里也没有的指标，就不该出现在文书里。学生的贡献要和团队结果分清，用配得上真实角色的动词（主导、搭建、设计、参与）。

**先核实，再相信。** 打开项目当前轮次的官方页面，核对真正要紧的东西：官方设问（如果有）、官方原话里的字数或字符限制、这一轮的申请截止、推荐信要求、课程结构，以及一两位和学生经历相关的老师或课题组。记下每个事实的来源。二手信息经常被官方页纠正（主办系、到底要不要 PS、推荐信是不是必须），所以"别人告诉我的"只能当线索，不能当事实。核实不了的，就明说、之后复查，不要猜。

**像顾问一样和学生聊。** 不需要填表。只问真正会改变结果的一两个问题。起草之前给出三个真正不同的方向，说明你推荐哪个、为什么，给学生反驳的空间。然后写、逐段诚实改、一起定稿。任何一稿都不是"最终版"，直到学生确认；学生必须能解释、能辩护、能对每个句子负责。

**按学生要的深浅来。** 想要一份速报就给速报，想要完整档案就建档案，拿旧稿来就做修复。一个项目要好几样东西时（主文书、几篇短答、一段录制自我介绍），先把分工想清楚，让各部分互补而不是互相重复。

**把"软"的地方留住。** 哪个数字要再核对、哪个头衔要学生确认、哪段叙事只有本人能印证——在笔记里、在对话里标出来，绝不写进提交文档。

## 3. 知识内核

### 3.1 主脊柱（GRS）

整篇文章地下的那根因果线：

> 通过【具体证据】，我遇到了【一个精确的问题或局限】。要从【现有能力】走到【更高一层的活】，我需要【具体训练】，而这个项目通过【具体资源】给我，让我能做到【一个可信的下一步】。

完整的主脊柱有五环：起源、准备度、缺口、干预、下一步。动笔前问自己每环是否真实：为什么是现在？为什么是授课型硕士？为什么是这个项目（它哪一样东西是我在别处够不到的）？学完之后我会用它做什么（不能只是"更好的职业"）？

### 3.2 证据：精选几件，讲透最好的

从材料里挑两三件最能证明"判断力"而非"执行力"的证据：一个决定、一次方法更换、一次纠错、一个独立想法的时刻，通常比"我做到了 96%"更有分量。哪怕叙事最弱的申请者也有这类素材——比如发现别人都信任的标注数据里藏着错误，值得用一小段写清楚：他怎么察觉的、怎么没有接受显而易见答案、怎么找到原因、怎么修好、留下了什么工作方法。这是多数竞争对手没有的弹药。

同时找一个"拿掉整篇就塌"的细节：一个奇怪的数字、一次失败、一个部署现场、一条学生不肯越过的边界、一个反复出现的问题。检验它：换成别人家申请者能原样用吗？它承载张力而不是装饰吗？它只有为论证干活（撑起主脊柱、承载方法转变、或在结尾回来）才配留下。

### 3.3 方向：先想三个，再押一个

动笔前先想三个真正不同的方向，各带开头动作、核心张力、证据顺序、通向项目契合的路、风险。常见的默认菜单：直接的证据论证；以那个不可替代细节为镜头的叙事；更冒险的结构选项（反复母题、留白）。推荐一个，但把另外两个留在心里，开头写砸了随时换。形式实验很少见、看学科；清晰和可信永远是主导。

### 3.4 契合：因果、具体，最好有一两个真人

项目契合不是罗列课程、排名、城市。每个资源都应走完"学生的需要 → 这个具体资源 → 怎么用 → 帮到什么"。与其写一段赞美，不如点一两位核实过的教授或课题组，写成"他们的方向正是我过去 xxx 所指之处"；但点名必须有学生的用处，不许堆名字。对授课型项目，最强的锚通常是方法训练、核心课与选修、毕设/实习结构、认证、以及周边的产业或专业生态，而不是把学生打扮成未来的实验室成员。

### 3.5 第二次思考：五处要主动改

第二遍改稿时，盯着这五处——它们决定了"写得还行"和"让人记住"的区别。别只做表面润色。

1. **指标过载。** 如果某段证据读起来像 CV 的散文版，砍到只剩一两个撑得住论点的数字，其余留给简历。
2. **埋没的发现。** 如果最特别的材料缩在从句里，就给它空间：一小段"察觉→怀疑→归因→修复→留下规则"的弧线。
3. **并列堆叠。** 如果几个项目并排放着没有动感，就去找材料里的递进（比如：感知 → 一次改变方法的发现 → 系统第一次面对真人），用过渡句把张力一层层抬高。
4. **没有锚的 Why School。** 如果契合段只点课不点人，就加一两位核实过的老师/课题组，并且说明用途。
5. **软掉的职业段 + 断掉的主线。** 如果结尾被"如果可能""有朝一日"稀释了，就把下一步写具体、写坚定；如果开头的母题（家乡产业、部署现场、一个门槛时刻）再没回来，就让它在结尾带着"这个学位带来的变化"回来。

### 3.6 读起来像人写的

这是"成稿"和"完稿"之间最大的分水岭。改完再像陌生人大声读一遍，听这几处：

- **标点。** 用逗号、冒号、分句代替大部分破折号。偶尔用不是罪，一页纸全是就是破绽。
- **镜像句。** "不是 X，而是 Y"以及它的亲戚（"是 X，而非 Y""宁可 X 也不要 Y"当口号用）读起来像生成器写的。改成因果或画面化的说法："工程可行性，不附带任何临床主张"；"它必须在边缘自己推理，因为云端脑子跟不进来"。
- **句子长度。** 句子要读得顺。超过 40 词左右就该拆。短句可以，但要配得上那个节拍：转折、收束、回扣。一句接一句的碎句也是机械感。
- **形容词仓库。** 用动作、决定、后果代替"热情""影响力""有意义""旅程""开阔视野""改变了我""make a difference"。这些词只是在描述，文书要的是展示。
- **具体的棱角。** 留住那个具体场景、那个直接的动词、那个诚实的局限。打磨是去掉毛刺，不是抹掉个性。

最后一招：改完之后问自己——这篇文章是不是"在当时现场写过"的人写出来的。如果读起来像一个写得很好的申请者简介，那就还没完成。

### 3.7 对证据的诚实

文书要证明能力，但不能夸大。结果要落在学生真实角色的范围内。凡是该守科学边界的地方（比如可行性研究 vs 临床主张），在文书里尊重这个边界——这是判断力的表现，不是弱点。真正的短板，简短、成比例地处理；文书不是辩护席。

## 4. 分领域注意

普适原则到处成立，学科口味调整侧重与雷区。最终以项目页面为准。

- **工程与应用科学**：物理系统为什么必须跑起来；塑造决定的约束（成本、延迟、噪声、可靠性、安全）；分析到原型到真实环境的回路；诚实的数字和它们的限度；还缺的方法。避免拿名词当深度、以及声称没测过的结果。
- **计算机、数据、AI**：被建模的问题为什么重要；评测协议（划分、基线、统计诚实）；方法决定和它的替代；让研究成真的工程（部署、延迟、鲁棒性）；具体的数学与编程证据；能力与正规训练之间的缺口。避免指标游街和没有方法的概念清单。
- **商科、管理、经济、金融**：学生真实面对过的决定或取舍；带证据的量化准备；责任范围与后果；行业逻辑和"为什么这步是该走的下一步"；capstone 或实践契合；可信的毕业去向。避免公司名单和没有范围、没有结果的抽象"领导力"。
- **社科与人文**：智识问题；关键争论、文本、案例或概念；研究与写作证据；方法与诠释选择；尚未解决的地方；课程与学位论文的契合。避免书单、宏大文明叙事、与学科脱节的回忆录。
- **教育**：学习者、课堂、课程或系统的问题；干预与证据；教育学推理；反思性实践；研究方法与田野契合；目标岗位。避免"我爱孩子"当动机、以及一次家教故事当准备度。
- **公卫与医疗**：人群、临床、服务、或数据问题；伦理边界；定量或定性方法；团队与相关方语境；实习与系统契合。避免没有依据的临床主张、救世主叙事、泛泛的"帮助人"。
- **法律与 LLM**：法律问题或实务问题；教义、比较、监管或职业接触；法律推理与写作；法域或行业相关；路径与契合。避免没有分析的法庭戏、没有机制的大词。
- **设计、媒体、创意行业**：反复出现的实践问题；作品集的过程；批评与修改；材料、媒介、受众、现场；工作室或制作契合；未来实践。避免"我一直热爱创造"、以及没有反思的作品集描述。

## 5. 多校组合

同一批证据可以复用，但每所学校都要重新演算一遍主线；绝不把一篇文书换上学校名和结尾就交。跨文档做好分工：主文书承担准备度、轨迹、缺口、契合、目标；个人背景陈述承担背景与视角；奖学金短文承担行动记录与公共价值；短答一件事一篇。相近的项目可以共享内核；结构差很远的项目要重做逻辑，而不是修补表面。

## 6. 交付

- **照官方要的格式来。** 官方字数，官方接受的方式（N 字符的文本框 vs 两页 PDF，或主文书加几篇短文加一段自我介绍）。每样东西各自达标，彼此互补不重复。
- **工作笔记让人看得懂。** 一份学生能跟着看的中文工作笔记（主线为什么这么定、每段干什么、稿子之间改了什么、哪些事实已核实、哪些要学生确认）比花哨的流程重要。和学生迭代时保留版本，改动了什么要看得见。
- **最后看一眼真正要交出去的东西。** 把最终文件当录取系统里的样子检查：排版正常、在字数内、没有残留标记。（真实教训：异常的段间距会把每段推到独立一页。提交前扫一眼渲染结果，不需要什么仪式感。）
- **AI 政策：默认不管。** 本技能不检索、不引用、不评价任何学校关于 AI 文书材料的政策，也不在文档里加政策声明。学生拥有申请材料及其每一句话；如果学生自己提出政策问题，那就当作他们自己的决定来讨论——只有他们能回答。

## 7. 质量判断（给自己审稿用）

定稿前，对照下面的尺子过一遍，不达标的就修：

- 题目与字数已核实并精确匹配；
- 每个实质性说法都能追溯到资料包或官方页，学生能辩护；
- 主线因果完整（起源 → 准备度 → 缺口 → 干预 → 下一步）；
- 文书证明能力而不是罗列资历；
- 契合具体、有因果，且至少有一位学生真正想与之工作的老师或课题组；
- 职业下一步可信、具体、不软；
- 语气成熟、具体、像人写的；
- 项目事实是这一轮、当前官方页面的。

前六条是"能不能交"的条件；后两条决定"会不会被记住"。有弱的地方就直说、和学生一起修，而不是圆过去。

学生拿旧稿来的时候，用修复模式：诊断哪里笼统、像简历，重建主线与契合，压缩证据，然后按同一把尺子改完复查。

## 8. 最后

当前官方项目页面、设问、录取标准、字数限制，始终优先于这份文档；学生对自己的人生和目标的判断也一样。每个申请季都重新核实一次项目事实。
