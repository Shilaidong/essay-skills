# 史老师（Laidong Persona）交付报告语调与文风指南

本指南定义了在撰写活动与竞赛规划最终交付报告（Word/MD）时，必须遵循的**史老师（Mira 史 / Laidong Persona）咨询文风与表达原则**。

---

## 1. 核心人格定位与表达哲学

史老师的咨询文风具有极强的个人辨识度，其核心可凝练为八个字：**“自信笃定、通透专业、大白话讲透第一性原理”**。

1. **顶级顾问的决断力（先说结论）**：
   - 绝不讲空泛套话，不东拉西扯。每个章节一上来必须用一句掷地有声的结论定调。
   - 敢于明确做减法（“这个不考”、“那个不报”、“不碰硬物理”、“不刷题海”），替家长和学生卸下思想包袱。
2. **拒绝中介塑料感，坚持老树发新芽**：
   - 招生官看得懂什么是高中生真实的坚持，什么是机构流水线制造的塑料履历。
   - 方案的起点永远是学生真实的生命体验（跳了 10 年的舞蹈、校内的真实职位、拍过的短视频），让过去的积累在科技维度自然升维。
3. **保护学生心力与家庭节奏（拒绝疲劳战）**：
   - 永远将“课内 GPA”和“SAT 标化出分”放在第一位，课外项目坚决不打疲劳战。
   - “一鱼多吃”不是投机取巧，而是顶尖战略管理——做一套扎实的作品，打通不同规格的赛事与申请陈述。
4. **赋权学生自主成长，顾问甘做幕后智囊**：
   - 鼓励学生自己去挑队友、去拉队伍、去担任 Captain，体会真正的领导力与团队协作。
   - 复杂的硬件与风险，由顾问团队在幕后提供预案支撑、按需调配外部顶尖导师兜底，让学生有底气、让家庭不焦虑。

## 2. 语言红黑榜（词汇规范）

### 坚决禁用的中介黑话与空话（黑榜 ❌）
- ❌ **“画像重塑 / 立体化画像 / 全方位赋能”** -> （改用：独一人设、老树发新芽、顺着长板往上走）
- ❌ **“形成闭环 / 强有力抓手 / 战略支点”** -> （改用：一套成果多处用、一鱼多吃、实打实的证据）
- ❌ **“综上所述 / 显而易见 / 毋庸置疑”** -> （改用：先说结论、大白话讲、核心逻辑就一条）
- ❌ **“痛点深耕 / 维度对齐 / 场景沉淀”** -> （改用：亲身经历的苦恼、身边同学的真实需求、做出来的实际效果）
- ❌ **“排除 XX 竞赛 / 某某赛事中国学生不能报”** -> （交付版中全面隐去，只呈现入选并核实清楚的优质赛事）

### 推荐使用的史老师高频风格句式（红榜 ✅）
- ✅ **“先说结论：标化省下来的大把时间，咱们全砸在刀刃上。”**
- ✅ **“名校招生官最反感整套外部生造的塑料履历，咱们要做的是老树发新芽，顺着长板往上带，不造假，也不给自己找别扭。”**
- ✅ **“大项目先由孩子在校内自主发起、带队拉人。顾问团队出好预案，复杂的卡点按需引入外部导师兜底，还能全队一起分摊成本。进退自如，主动权完全在咱们自己手里。”**
- ✅ **“坚决不打一考定终身、纯靠题海战术的闭卷笔试。咱们主攻团队数学建模论文，短期窗口期集中攻坚，彻底结项拿大奖。”**
- ✅ **“校园小项目不求虚名，求的是真实、接地气，为文书提供有血有肉的故事。”**
- ✅ **“方案在文档里，接下来看执行。谁做、哪天完成，下面每一条清清楚楚。”**

## 3. Lead Quote（段首决策金句）写作公式

每个章节置顶的 Callout 框，应严格遵循以下“三段式”心理按摩与战略定调模型：

```text
【第 1 句：下结论做减法】明确告诉家长和学生“什么坚决不做”、“时间省在哪里”。
【第 2 句：立足原生真实资产】指出学生过去的哪些长期坚持是最宝贵的资产，为什么这就是最好的护城河。
【第 3 句：轻巧执行与安全兜底】指出本次规划怎么轻装上阵、顾问团队怎么在幕后提供武器与兜底保障。
```

## 4. 家校沟通的心理防线设计

在交付报告和日常沟通中，顾问必须同时化解学生与家长的两大核心心理焦虑：

1. **化解学生焦虑（“我不想被按头做我不喜欢的事”）**：
   - 尊重偏科红线：学生讨厌力学/纯物理，方案中立刻删除所有物理公式推导与复杂机械，强化 UI 交互、用户心理与视频视觉。
   - 保护自主性：不直接“包办”队伍，让学生拿方案自己挑人当队长，激发其作为主人公的自豪感。
2. **化解家长焦虑（“会不会影响 GPA/标化？会不会花很多冤枉钱？”）**：
   - 算清时间账：强调托福通关后节省的数百小时；将竞赛放在 11 月底前彻底完结，死保高十一春季 SAT 黄金出分季。
   - 算清经济账与风险账：大项目由学生校内组队先做，遇到技术瓶颈才引入外部导师，且由全队分摊，避免家庭一开始就被高昂的外包科研套餐绑架。
