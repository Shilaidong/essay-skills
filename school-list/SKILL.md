# 选校名单

给学生找选校。先读学生文件夹和对话框，再查本地库，再用**真浏览器**分路搜索，最后由总 Agent 出大约 20 所，填进选校模板。后续还要人工核对，名单不能少。

怎么找见 [strategy.md](strategy.md)：**学校是第一位**；找既好看、又好申、又匹配的；同一所尽量**一高一低**；别全搞难的。太神的可以申一下试试，主体走最好录的口，进了再定专业。

本包不管整份规划案、甘特图、Word。那种走规划案 skill。若已加载顾问本人的口吻包，判断句按那份写。

## 必须遵守（用户原话）

- 必须使用浏览器进行网络搜索。**Mac 强制用 ego-lite**（技能名 `ego-browser`，命令 `ego-browser`）。**Windows 强制用 Browser OS NEO**。不准换成内嵌预览、Chrome、命令行浏览器或搜索 API 凑合。缺了就停，让用户把对应浏览器/技能装回来，再继续。
- 需要使用多 sub-agent 针对学生的情况去搜索。第一是查项目；第二是要去网络论坛上找。
- 建议去“一亩三分地”等国内留学论坛，查看经验帖；也可以在谷歌上找其他网站的帖子，以及去小红书上搜一搜。
- 小红书可能需要登录。如果遇到需要登录的情况，让用户在浏览器里扫二维码登录。
- 去搜一搜、看一看，一定要理解内容，不能光看标题就行。
- 为什么要开 sub-agent 去做？因为每个 Agent 都有自己的上下文。
- 各 sub-agent 之后需将结果总结汇报给总的选校 Agent。总 Agent 在权衡各方内容后，提出来一份学校名单。
- 初步选出的名单不能少，因为后续还要人工核对，数量基本上要定在 20 个学校左右。
- 在选校之前，我会跟用户沟通他的目标是什么样的学校，有没有什么偏好，这些我都会跟他说。
- 选校列表也是一个模板。发出选校 skill 时，我会把这个模板的本地链接一块写上。
- 工作文件夹就在那个学生的工作文件夹里。需要提前阅读该文件夹里的全部内容，然后再派发搜索学校的任务。
- 同时也要关注文本框里给出的许多信息，优先以文本框信息为主。有问题再问，没问题的话不要问得特别细。

## 开工顺序

### 0. 路径（不要写死）

换电脑、换盘符、换新库都是常态。**禁止把某台机器的 `C:\Users\...` 写进回复或当默认值。**

优先顺序：

1. 对话框里用户这次丢来的本地链接
2. 环境变量 `SCHOOL_NAVIGATOR_DB`、`SCHOOL_LIST_TEMPLATE`、`SCHOOL_LIST_ROOT`
3. 按**文件名**找，取修改时间最新的一份：
   - 库：`school-navigator-catalog-*.sqlite`
   - 模板：`选校清单模板.xlsx`
4. 还没有，问**一次**，让用户把链接丢进来，给完立刻继续

```bash
python scripts/resolve_paths.py --work "<学生工作文件夹，可空>" --db "<用户给的库，可空>" --template "<用户给的模板，可空>"
```

找到了要告诉用户用的是哪两个文件。多个库并存时用最新的，不要用 skill 里记过的旧日期文件名。

| 要什么 | 认什么 |
|---|---|
| 选校库 | 用户链接，或最新的 `school-navigator-catalog-*.sqlite` |
| 选校模板 | 用户链接，或 `选校清单模板.xlsx` |
| 学生工作文件夹 | 用户给的文件夹；没有就只用对话框和已上传文件 |

怎么找：[strategy.md](strategy.md)。库怎么查：[catalog.md](catalog.md)。浏览器怎么调：[browser.md](browser.md)。Excel 怎么填：[template.md](template.md)。

### 1. 先读完再搜

1. 读学生工作文件夹里的**全部**文件（成绩、旧名单、纪要、截图说明都算）。
2. **优先以文本框信息为主。** 对话框和文件夹打架，听对话框。
3. 选校之前，用几条短句跟用户对齐：目标国家/学位、专业口、学校要好看还是先求稳进、有没有地区/预算/批次偏好。已经有就复述，**没问题不要问得特别细**。对齐时带一句：我按学校第一、同校一高一低来找，名单不会全是难的。
4. 缺「国家或地区 + 本科/硕士 + 专业方向」这三件才追问。GPA、标化、偏好有就用，没有先出名单，标「还需要核对」。

### 2. 查库（总 Agent 自己做）

只读打开 sqlite。用本包脚本，不要臆造库里的学校：

```bash
python scripts/query_catalog.py --db "<sqlite路径>" --q "<专业关键词>" --country US --degree ug --limit 40
```

国家、学位、关键词按学生情况改。同一所学校至少跑两套词：他真正想学的（高），以及招人更多、更好进的相邻口（低）。不要只搜最热那个专业名。细则见 [catalog.md](catalog.md)。

先读这份库的 `meta`（`resolve_paths.py` 会带出来）：转储时间、学校数、项目数以**当前这份文件**为准，不要用旧笔记里的日期和计数。这类库一般是 School Navigator 快照，**本科项目多、硕士少**；港新澳欧加等常在 `OTHER`。库里没有的学校，允许浏览器补，但要写清来源。截止日期、学费、语言分以官网为准，库只能当线索。

### 3. 再派 sub-agent（至少两路，建议三路并行）

读完文件夹、对齐偏好、查完库之后，再派。每个 sub-agent 自己的上下文，互不读对方网页。

| 路 | 搜什么 | 必须交回 |
|---|---|---|
| A 项目 | 官网：高/低两个项目页、转专业/院是否卡死、招生规模、课程 | 每个学校尽量交回一高一低；URL、要求、好不好进、进了能不能转 |
| B 论坛 | 一亩三分地：哪个口好申、哪个太卷、转专业；谷歌同类帖 | 帖子 URL、年份、作者背景、正文里怎么说，不是标题 |
| C 小红书 | 学校+专业+好申/转专业 | 同上；要登录就停，让用户在浏览器里扫二维码，不要自己绕 |

每路必须用真浏览器，规则见 [browser.md](browser.md)。Mac 走 `ego-browser`，Windows 走 Browser OS NEO。禁止把 Tavily / 纯搜索 API 当主路径。禁止只交标题列表。对应技能或命令不在，停下来告诉用户，不要换别的浏览器。

派活时写清：学生画像（脱敏）、库里已圈的候选、要搜的中英文关键词、最多看多少页。不要把整份成绩单和学生证件丢给 sub-agent。

### 4. 总 Agent 出名单

收齐各路汇报后，按 [strategy.md](strategy.md) 权衡，提出一份学校名单：

- **大约 20 所**（按学校计，18–22 可接受）。不要 8 所交差，也不要 20 所全是最难的。
- 分层用模板用词：**冲刺 / 匹配 / 保底 / 彩票项**。匹配是主体。彩票项 2–4 所即可，写「可以申一下试试」。
- **同一所尽量两行：一高一低。** 低的是主申、更好进；高的更贴他想学的，进了再转或双专业。配不出第二个，顾问说明写原因。专业行数应明显多于学校数。
- **先核好转不转。** 好转：低口主申。转死了：低的必须落在对的学院。几乎转不了又对不上，先 pass。
- 每一所答得上：好看、好申、匹配。不能只盯最前面那一档。美本还要标 ED/EA/RD 是否互斥（知道才写）。
- 论坛和小红书当案例和舆情，不当官方要求。
- 不保证录取。不编排名、录取率、分数线。

把名单填进模板的副本，不要改原模板。复制到学生文件夹 `选校清单.xlsx`，用脚本填：

```bash
python scripts/fill_list.py --template "<模板xlsx>" --out "<学生文件夹>/选校清单.xlsx" --student "<姓名>" --json rows.json
```

`rows.json` 字段见 [template.md](template.md)。大约 20 所唯一学校；同校可多行专业。空字段写「还需要核对」。顾问说明写短，论坛只作依据不是官网。需要的话另存 `选校依据.md` 放帖子 URL，不要把论坛长文塞进格子。

## 质量门

- [ ] 文件夹已通读，或用户确认没有文件夹
- [ ] 对话框优先于文件夹
- [ ] 偏好已用短句对齐，没有盘问细表
- [ ] 用这次解析到的 sqlite 查过，且是只读；回复里没有写死旧机器路径
- [ ] 项目 + 论坛（+ 能开的小红书）都用指定浏览器看过正文：Mac = ego-lite，Windows = NEO
- [ ] 约 20 所；匹配是主体，不是全冲难的
- [ ] 多数学校有一高一低两行，或说明了为什么只有一个口；专业行数明显多于学校数
- [ ] 顾问说明能看出：学校第一、低的更好进、高的进了再转；转不转得了写清了
- [ ] 学生文件夹里有填好的 `选校清单.xlsx`；原模板没被改；空字段标「还需要核对」
- [ ] 没有学生证件号、电话；举例用「学生 A」

## 不要

- 没读文件夹就派搜索
- 用搜索摘要代替打开帖子
- Mac 不用 ego-lite、Windows 不用 NEO，或缺了还硬搜
- 把 sqlite 路径当成选校模板
- 把本 skill 写成完整规划案
- 代考、买分、假材料、保证录取
