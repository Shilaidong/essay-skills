# 怎么喊

用户（路径每次现贴，不要沿用上次电脑上的盘符）：

```
加载 school-list。
库：<这次的 school-navigator-catalog-*.sqlite>
模板：<这次的 选校清单模板.xlsx>
学生文件夹：<这个学生的工作文件夹>
目标：美本，应用物理/工程，想留美，预算中上，不绑东海岸。按我刚才说的背景来。
```

只丢文件夹和几句偏好也可以。没给库/模板时，按文件名找最新的；找不到再问一次。

换机或更新库以后：把新文件链接丢进对话框，或设环境变量 `SCHOOL_NAVIGATOR_DB`、`SCHOOL_LIST_TEMPLATE`。
