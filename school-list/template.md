# 选校清单模板

认文件名 `选校清单模板.xlsx`。用户这次丢来的链接优先；否则 `scripts/resolve_paths.py` 按文件名找。不要写死某台电脑的路径。

不要改原模板，复制到学生工作文件夹再填，文件名：`选校清单.xlsx`。

## 表结构（工作表 `选校清单`）

| 格 | 含义 |
|---|---|
| B2 | 学生姓名（有证据才写，不要从拼音猜） |
| D2 | 导出日期 |
| F2 | 唯一学校数（脚本会改） |
| H2 | 专业选择数（脚本会改） |
| A4:H4 | 表头，不要改 |

从 **A5** 起一行一个专业：

| 列 | 字段 | 怎么填 |
|---|---|---|
| A | 策略分组 | 只能写：`冲刺` / `匹配` / `保底` / `彩票项` |
| B | 学校名称 | 中文名优先，没有就英文 |
| C | 专业名称 | 官方项目名 |
| D | 学位类型 | 如 BS / BA / MSc / Master |
| E | 所属学院 | 官网或库里的学院 |
| F | 国家 / 范围 | 如 美国、英国、香港、新加坡 |
| G | 专业官网 | 浏览器核对过的项目 URL |
| H | 顾问说明 | 为什么放、风险、还需要家庭确认的。论坛当案例，不当官方要求 |

工作表 `填写说明` 原样保留，不要改。

主计数按**唯一学校**。大约 20 所学校；同一所学校可以多行专业。同校多专业时学校只计一次。

## 填写

```bash
python scripts/fill_list.py --template "<模板xlsx>" --out "<学生文件夹>/选校清单.xlsx" --student "<姓名>" --json rows.json
```

`rows.json` 是对象数组，字段：`group, school, program, degree, college, region, url, note`。

`group` 可写 冲/稳/保，脚本会收成 冲刺/匹配/保底。行数超过模板空行时自动加行，样式跟着第 5 行。

空字段写「还需要核对」，不要编链接和分数线。
