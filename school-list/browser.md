# 浏览器

网络搜索必须走本机真浏览器。不要用搜索摘要 API、或只读结果列表当主路径。

## 用哪个（强制，不要换）

先看操作系统，再开对应那一个。告诉用户这次用的是哪一个。

| 系统 | 必须用 | 怎么认 |
|---|---|---|
| macOS | **ego-lite** | 技能名 `ego-browser`；命令 `ego-browser`。先加载/按 `ego-browser` 那份 skill 操作（`ego-browser nodejs` heredoc、task space）。 |
| Windows | **Browser OS NEO** | 本机的 Browser OS NEO 应用 / 已接好的 NEO MCP。不要用别的 Chromium 壳顶替。 |

不准用：聊天窗口内嵌预览、系统 Chrome/Edge、无头抓取、Tavily / 纯搜索 API。

缺了就**停**：

- Mac 没有 `ego-browser` 命令，或找不到 `ego-browser` 技能：不要改用别的浏览器。让用户打开 ego lite，再走一遍引导；或从应用包把 `ego-skills/ego-browser` 拷回各 Agent 的 skills 目录。应用一般在 `/Applications/ego lite.app`。网站：https://lite.ego.app/
- Windows 没有 NEO：不要改用别的浏览器。让用户打开 Browser OS NEO，把 MCP/权限接好再继续。

需要登录授权时，走该浏览器自己的授权，不要改成无头抓取。小红书要扫码，停下来等用户在**这个**浏览器里登好。

本包**不含** ego-lite / NEO 技能。装 `school-list` 只许装这一夹，不要把整个技能仓覆盖到 skills 目录上。

## 各路怎么搜

搜的时候带着 [strategy.md](strategy.md)：每个学校尽量核一高一低，盯好转专业、哪个口好申，不要只盯最难那个项目。

**项目（sub-agent A）**

每个候选学校打开**两个**相关项目页（高 / 低），再看学院页、Admission / How to apply、转专业或换学院说明。读入学要求、课程、学制、截止日期、语言分、招人规模（有就记）。同一项目至少点进要求页和课程页，不要只看首页标题。

交回时标明：哪个更好进、进了能不能转到另一个。

**论坛（sub-agent B）**

1. 一亩三分地：学校名 + 专业 + 好申/转专业/哪个好进。打开正文，记下年份、本科背景、GPA/标化（帖子里有的才记）、录了什么口、进了有没有转成、踩了什么坑。
2. 谷歌：同样关键词，打开其他网站的帖子（留学博客、Reddit、The Student Room、GradCafe 等），同样读正文。

旧帖（三年以上）当参考，不要当成今年政策。

**小红书（sub-agent C）**

搜学校+专业+好申/转专业。点开笔记看全文。

小红书可能需要登录。如果遇到需要登录的情况，让用户在浏览器里扫二维码登录。等用户说登录好了再继续。不要截密码，不要自己绕登录墙。

## 交回格式（给总 Agent）

每条：

```
来源：官网 | 一亩三分地 | 谷歌帖 | 小红书
学校 / 项目：
URL：
年份或页面日期：
读到的要点：（3–8 句，必须是正文里的，不是标题改写）
这口是高还是低：高（更贴他想学） / 低（更好进、主申）
和这个学生：对口 / 偏难 / 偏易 / 不对口
进了能不能转：
还需要核对：
```

看不懂的段落标「没看懂，待核」，不要脑补。
