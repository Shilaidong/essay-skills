# 浏览器

网络搜索必须走本机真浏览器。不要用搜索摘要 API、或只读结果列表当主路径。

## 用哪个

看本机有什么专用浏览器，有哪个用哪个，并告诉用户这次用的是哪一个。

| 系统 | 优先 |
|---|---|
| Windows | Browser OS NEO（或同类型的本机专用浏览器） |
| Mac | EGO（或同类型的本机专用浏览器） |

不要用聊天窗口里的内嵌预览页凑合。专用浏览器都不可用时，才退到命令行浏览器，用之前先说一声。

需要登录授权时，走该浏览器自己的授权，不要改成无头抓取。

## 各路怎么搜

搜的时候带着 [strategy.md](strategy.md)：每个学校尽量核一高一低，盯好转专业、哪个口好申，不要只盯最难那个项目。

**项目（sub-agent A）**

每个候选学校打开**两个**相关项目页（高 / 低），再看学院页、Admission / How to apply、转专业或换学院说明。读入学要求、课程、学制、截止日期、语言分、招人规模（有就记）。同一项目至少点进要求页和课程页，不要只看首页标题。

交回时标明：哪个更好进、进了能不能转到另一个。

**论坛（sub-agent B）**

1. 一亩三分地：学校名 + 专业 + 好申/转专业/哪个好进。打开正文，记下年份、本科背景、GPA/标化（帖子里有的才记）、录了什么口、进了有没有转成、踩了什么坑。
2. 谷歌：同样关键词，打开其他网站的帖子（留学博客、Reddit、The Student Room、GradCafe 等），同样读正文。

旧帖（三年以上）当参考，不要当成今年政策。

**小红书（sub-agent C）**

搜学校+专业+好申/转专业。点开笔记看全文。

小红书可能需要登录。如果遇到需要登录的情况，让用户在浏览器里扫二维码登录。等用户说登录好了再继续。不要截密码，不要自己绕登录墙。

## 交回格式（给总 Agent）

每条：

```
来源：官网 | 一亩三分地 | 谷歌帖 | 小红书
学校 / 项目：
URL：
年份或页面日期：
读到的要点：（3–8 句，必须是正文里的，不是标题改写）
这口是高还是低：高（更贴他想学） / 低（更好进、主申）
和这个学生：对口 / 偏难 / 偏易 / 不对口
进了能不能转：
还需要核对：
```

看不懂的段落标「没看懂，待核」，不要脑补。
